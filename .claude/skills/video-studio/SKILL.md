# استوديو الفيديو

هالمهارة بتوزّع الشغل على المهارات اللي بالريبو. ما بتعيد شي هي موجود فيهن: اقرأ المهارة المناسبة وامشِ على قواعدها.

| المهارة | شو بتعمل | ببلاش؟ |
|---|---|---|
| `hyperframes` (+ `hyperframes-cli`, `hyperframes-registry`, `media-use`) | فيديو كامل من HTML/GSAP ← MP4: مشاهد، نصوص متحركة، ترجمة، رسوم بيانية، خرائط، 450 بلوك جاهز | ✅ الرندر والـ CLI مجاني (Apache 2.0) |
| `reverse-engineer-video` (REV) | بياخد رابط فيديو + موضوعك، بيطلّع «مواصفات الأسلوب» وبيبني فيديو جديد بنفس الشكل بالكود (three.js / canvas) | ✅ MIT، كله محلي |
| `reverse-video` | تفكيك كامل لفيديو أو قناة: السكريبت، الهوك، القصّات، الإيقاع، الألوان، الخطوط، الموسيقا، المؤثرات ← `teardown.md` + `style.json` | ✅ MIT، محلي (نماذج ~3GB أول مرة) |
| `style-sampling`, `reverse-any-video` | قوالب جاهزة ونسخ فريم بفريم من HeyGen | ❌ ميزة Pro مدفوعة — لا تستعملها إلا إذا عمار طلب ودفع |

## الوضع المجاني (الافتراضي، قرار عمار 2026-11-24)

HyperFrames نفسه مجاني (مفتوح المصدر، والرندر على جهاز الجلسة). اللي بيكلّف كريديت هو بس خدمات HeyGen. فما منستعمل:
- `auth login` ولا أي تسجيل دخول بـ HeyGen.
- `media-use resolve/generate` من HeyGen (موسيقا، صور، أصوات، أفاتار).
- `cloud render`، و`style-sampling`، و`reverse-any-video`، و`usage`.
- و`events` (usage note): منتخطاه.

بدالهم منستعمل:
- **الصوت:** edge-tts (`reverse-engineer-video/scripts/tts.py`).
- **الموسيقا والمؤثرات:** مولّدة بالكود (`reverse-engineer-video/scripts/score.py`) أو بلاها.
- **الصور:** رسم بالكود (SVG/canvas/CSS).
- **الرندر:** `render` المحلي بس.

إذا ميزة طلبت تسجيل دخول أو كريديت: تخطاها بالبديل المجاني، وما توقف تسأل.

## أول مرة بالجلسة

1. `bash scripts/video-setup.sh` من جذر الريبو (بينزّل three.js/puppeteer وبايثون yt-dlp/edge-tts لـ REV، وبيسخّن HyperFrames CLI). آمن تعيده.
2. «usage note» تبع HyperFrames: تخطاه (الوضع المجاني).
3. المتصفح بالجلسة السحابية: `CHROME=/opt/pw-browsers/chromium`.

## الحالة 1: موضوع ← فيديو كامل

1. **الشكل:** إذا عمار ما حدد، افتراضي = عمودي 1080×1920، 45–60 ثانية (Shorts/Reels/TikTok)، عربي RTL. أفقي 1920×1080 بس لليوتيوب الطويل.
2. **السكريبت:** هوك بأول 2 ثانية (سؤال أو رقم صادم)، جملة لكل مشهد، 140–160 كلمة بالدقيقة، ختام بدعوة. اكتبه بـ `videos/<date>-<slug>/script.md` واعرضه على عمار 🛑 قبل البناء إلا إذا قال «كمّل لحالك».
3. **الصوت:** `edge-tts` ببلاش وفيه أصوات سورية: `ar-SY-LaithNeural` (رجل؛ بـ tts.py: `python scripts/tts.py script.json out ar-SY-LaithNeural`)، `ar-SY-AmanyNeural` (امرأة). عبر `reverse-engineer-video/scripts/tts.py` أو مباشرة `.venv/bin/edge-tts`. للإنكليزي: `npx hyperframes tts` (Kokoro محلي). خد توقيت الكلمات وركّب المشاهد عليه.
4. **البناء:** `/hyperframes`: `npx hyperframes init videos/<date>-<slug> --skip-skills --skill=hyperframes`، مشهد لكل جملة بـ `compositions/`، دوّر بـ `hyperframes-registry` قبل ما تبني أي عنصر بإيدك. الخطوط العربية تكون ملفات بـ `assets/fonts/` (Cairo، Tajawal، IBM Plex Sans Arabic من Google Fonts).
5. **الفحص:** `npx hyperframes check --json` ← صلّح كل خطأ، بعدين `snapshot` وشوف الفريمات بعينك.
6. **الرندر:** `npx hyperframes render --quality draft -o draft.mp4` للتجربة، و`--quality delivery -o final.mp4` للنهائي. تأكد بـ `ffprobe` من المدة والقياس، وطلّع فريمات وشوفها.
7. **التسليم:** ابعت `final.mp4` لعمار بـ SendUserFile (لا ترفعه على git). مع عنوان + وصف + 5 هاشتاغ + فكرة صورة مصغّرة.

## الحالة 2: رابط يوتيوب/قناة ← فيديو بنفس الأسلوب

1. **التحليل:**
   - سريع (الأسلوب البصري لفيديو واحد): REV المرحلة 0 و1 ← `style.md`.
   - عميق (قناة كاملة، 3–5 فيديوهات، الهوك والإيقاع والصوت): `reverse-video` ← `teardown.md` + `style.json`.
2. **«شو البرومبت/الوصفة»:** من التحليل اكتب `recipe.md`: وصف الأسلوب بجملتين، البنية بالثواني، قواعد الألوان والخطوط والحركة، الصوت، وبرومبت جاهز لإعادة الاستعمال («اعمل فيديو عن X بأسلوب Y: …»). هاد الجواب لسؤال «كيف هالفيديو متصمم».
3. **البناء:** REV (المرحلة 2 ← 6) إذا الأسلوب 3D/رسم بالكود، أو `/hyperframes` إذا موشن غرافيك ونصوص وترجمة. القصة جديدة دايماً.
4. **حلقة جديدة بنفس الأسلوب:** REV وضع B — انسخ `src/` من الحلقة السابقة وابدأ من المرحلة 2.

## قواعد ثابتة

- **الأسلوب بس، مش المحتوى:** ممنوع ناخد لقطات أو صوت أو موسيقا أو شخصيات أو اسم أو لوغو القناة الأصلية. الفيديوهات المنزّلة للتحليل بس، بمجلد مؤقت (scratchpad)، وما بتنرفع على git.
- **ببلاش أول:** ولا أداة مدفوعة (HeyGen Pro، أصوات مدفوعة، cloud render) إلا بطلب عمار مع الكلفة بالدولار.
- الفيديوهات النهائية ما بتنحط بـ git (`videos/**/*.mp4` بالـ .gitignore). المشروع (HTML + سكريبت + recipe) بينحفظ لنعيد استعماله.
- كل وصفة أسلوب نجحت ← احفظها بـ `styles/<name>/recipe.md` لحتى الحلقات الجاية تبدأ منها.
- بعد كل فيديو: درس قصير (شو صلّحنا وليش) بآخر `styles/<name>/recipe.md`.
